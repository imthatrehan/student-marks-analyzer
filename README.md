# Student Marks Analyzer

A vanilla JavaScript project that analyzes student marks.

## Features
- Calculate average marks
- Assign grades (A+, A, B, C, D, Fail)
- Find class topper
- Find fail students
- Subject-wise topper
- Passing percentage
- Class average
- Grade distribution

## Tech Stack
- HTML
- CSS
- JavaScript (ES6+)

## Concepts Used
- Array methods: map, filter, reduce, sort, flat
- Objects and destructuring
- Functions and higher-order functions
- DOM manipulation
